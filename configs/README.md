# Конфигурации

Значимые конфигурационные файлы стенда — для демонстрации настройки.

Перед добавлением файлов нужно убрать из них все секреты
(пароли индексатора/API, токены, ключи). Например:
indexer_password: '<REDACTED>'

Планируемые файлы:
- ossec.conf — конфигурация Wazuh manager (сбор логов, модули)
- 99-lab.conf — настройка sshd для стенда
- local_rules.xml — ссылка на ../rules/local_rules.xml
